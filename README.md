# Webサイト一括ダウンロード（ミラーリング）手順書 (wget編)

本手順書は、コマンドラインツール `wget` を使用して、指定したWebサイトの構成ファイル（HTML, CSS, JavaScript, 画像など）を一括ダウンロードし、ローカル環境で閲覧可能な状態で保存する方法を解説します。

---

## 1. 概要
本手法を使用することで、Webサイトのディレクトリ構造を維持したまま、ページ表示に必要なリソースを自動的に収集・保存できます。Python等のプログラムを記述する必要がなく、コマンド1行で実行可能です。

## 2. 実行環境
*   **推奨環境:** GitHub Codespaces, Linux (Ubuntu/Debian等), macOS
*   **前提:** ターミナル（コンソール）での操作が必要です。

## 3. 環境準備（GitHub Codespacesの場合）
GitHub Codespacesの環境には通常デフォルトで `wget` がインストールされていますが、念のため以下のコマンドで確認・インストールを行います。

1.  ターミナルを開きます。
2.  以下のコマンドを実行します。

```bash
sudo apt-get update && sudo apt-get install -y wget
```

## 4. ダウンロード実行コマンド

以下のコマンドをターミナルに入力して実行してください。
**※ `https://example.com` の部分を保存したい対象のURLに書き換えてください。**

```bash
wget \
  --mirror \
  --convert-links \
  --adjust-extension \
  --page-requisites \
  --no-parent \
  --wait=1 \
  https://example.com
```

### 短縮コマンド（同じ意味）
入力を短くしたい場合は以下を使用してください。

```bash
wget -mkEpnp -w 1 https://example.com
```

---

## 5. 各オプションの解説

上記のコマンドで使用しているオプションの意味は以下の通りです。

| オプション | 短縮 | 説明 |
| :--- | :--- | :--- |
| `--mirror` | `-m` | **ミラーリングダウンロード**を行います。<br>（再帰的取得、タイムスタンプ維持、深さ無制限を含みます） |
| `--convert-links` | `-k` | ダウンロード後、HTML内のリンク（CSS/画像パスなど）を**ローカル参照用に書き換えます**。<br>（オフラインでも正しく表示されるようになります） |
| `--adjust-extension` | `-E` | HTMLファイル等の拡張子（.html）がURLに含まれていない場合、自動的にファイル名に拡張子を付与します。 |
| `--page-requisites` | `-p` | ページの表示に必要な**すべての要素**（画像、CSS、音声など）をダウンロードします。 |
| `--no-parent` | `-np` | 指定したディレクトリより**上の階層へは移動しません**。<br>（サイト全体ではなく特定のパス以下のみを取得したい場合に重要です） |
| `--wait=1` | `-w 1` | サーバーへの負荷を防ぐため、リクエスト間に**1秒間の待機時間**を設けます。<br>（マナーとして必須の設定です） |

---

## 6. 実行結果の確認

1.  コマンドの実行が完了すると、カレントディレクトリ（現在のフォルダ）に、対象ドメイン名（例: `example.com`）のフォルダが作成されます。
2.  そのフォルダの中に、サイトの構造通りにファイルが保存されています。
3.  フォルダ内の `index.html` を開くことで、保存したサイトを確認できます。

### GitHub CodespacesからPCへダウンロードする場合
1.  左側の「エクスプローラー」で作成されたフォルダ（ドメイン名のフォルダ）を右クリックします。
2.  **「Download...」** を選択します。
3.  自動的に圧縮（ZIP等）され、ローカルPCへ保存されます。

---

## 7. 注意事項・免責事項

*   **サーバー負荷への配慮**
    `--wait` オプションを必ず使用し、短時間に大量のリクエストを送らないようにしてください。攻撃とみなされる可能性があります。
*   **robots.txt の遵守**
    `wget` は標準で `robots.txt`（クローラー拒否設定）に従います。ダウンロードされないファイルがある場合、サイト側で禁止されている可能性があります。無視してダウンロードする行為は避けてください。
*   **著作権と利用規約**
    ダウンロードしたデータは、私的利用または検証目的に留めてください。無断での再配布や、著作権を侵害する商用利用は法律で禁じられています。対象サイトの利用規約を必ず確認してください。
