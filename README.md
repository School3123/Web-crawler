# Webサイト全資産取得クローラー 取扱説明書

本ツールは、指定されたWebサイトからHTML、CSS、JavaScript、画像、そしてCSS内に記述されたフォントファイル等の資産を階層構造を維持したまま一括ダウンロードし、プレビューおよびZIP配布を行うためのツールです。

---

## 1. 準備事項

GitHub Codespaces 上で以下の2ファイルを作成してください。

1.  **`requirements.txt`**:
    ```text
    streamlit
    requests
    beautifulsoup4
    ```
2.  **`app.py`**:
    (提供された最新のスクリプトコードを貼り付けて保存してください)

---

## 2. セットアップ・起動方法

1.  **ライブラリのインストール**
    ターミナルで以下のコマンドを実行します。
    ```bash
    pip install -r requirements.txt
    ```

2.  **アプリケーションの起動**
    以下のコマンドでStreamlitサーバーを起動します。
    ```bash
    python -m streamlit run app.py
    ```

3.  **ブラウザで開く**
    ターミナルに表示されるリンク、またはCodespacesの右下に表示される「Open in Browser」ボタンをクリックして操作画面を開きます。

---

## 3. 使用方法

1.  **URLの入力**: 取得したいWebサイトのトップURLを入力します。
2.  **クローリング開始**: 「クローリング開始 (全資産取得)」ボタンをクリックします。
3.  **進捗確認**: 画面上のプログレスバーと、現在取得中のファイル名がログとして表示されます。
4.  **結果の確認**:
    *   **ファイル構造タブ**: ダウンロードされたファイルがどのフォルダ階層に保存されたかをツリー形式で表示します。
    *   **プレビュータブ**: 取得したサイトの見た目を簡易的に確認できます。
5.  **ダウンロード**: 「ZIPファイルをダウンロード」ボタンをクリックすると、すべてのファイルをまとめたZIPアーカイブがローカルPCに保存されます。

---

## 4. 主な機能と特徴

*   **全資産の自動追跡**: HTML内のタグ（img, script, link等）だけでなく、CSSファイルを解析してフォントファイル（.woff, .ttf）や背景画像も自動で特定しダウンロードします。
*   **ディレクトリ階層の再現**: サーバー上のパス構造をそのままローカルフォルダとして再現するため、リンク切れが起きにくい状態で保存されます。
*   **robots.txt の無視**: 標準的なクローラー制限をバイパスしてリクエストを送信します。
*   **モダンサイト対応**: `srcset` や `data-src` といった遅延読み込み用のアトリビュートからもURLを抽出します。

## 5. 注意事項（必ずお読みください）

1.  **著作権と法的遵守**: 
    ダウンロードしたコンテンツの著作権は元の所有者に帰属します。私的使用の範囲を超えた利用（無断転載・再配布など）は法律で禁じられている場合があります。
2.  **サーバーへの負荷**: 
    短時間に大量のリクエストを送信すると、対象サーバーに負荷をかけたり、IP制限を受ける可能性があります。常識の範囲内での利用をお願いします。
3.  **動的コンテンツの制限**: 
    JavaScriptを実行した後に生成される要素（SPAなど）の一部は、本スクリプト（静的解析）では取得できない場合があります。
4.  **セキュリティ**: 
    証明書エラーを無視する設定（verify=False）が含まれているため、信頼できるサイトに対してのみ使用してください。
